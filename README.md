# Gradient Spaces website skeleton

This is a static first-pass skeleton for a refreshed Gradient Spaces Lab website.

## Files

- `index.html`: typographic home page with news, featured projects, and connect links.
- `people.html`: roster page populated from structured lab data.
- `research.html`: research themes and selected project cards.
- `data.js`: structured roster, publication, chapter, and dataset data mirrored from the current Gradient Spaces site.
- `styles.css`: shared responsive visual system inspired by the REAL Stanford site direction.
- `script.js`: mobile navigation and data rendering for people/research pages.

## Design direction

- Sparse fixed header and narrow max-width layout.
- Large stacked typography on the homepage.
- Stanford cardinal accent with neutral text and restrained secondary colors.
- Public Gradient Spaces imagery is referenced remotely for the first skeleton.
- People and research content is rendered from `data.js` so future updates can happen in one place.

Open `index.html` in a browser to preview. No build step is required.
